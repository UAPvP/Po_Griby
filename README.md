# 🍄 Po Gryby (По гриби)

**Po Gryby** — це консольна тайлова гра на C#, у якій гравець досліджує ліс, взаємодіє з об'єктами та персонажами, збирає ресурси й бере участь у RPG-битвах. Гра матиме сюжет, анімації в консолі та систему взаємодії з навколишнім світом.

## 🎮 Основні можливості

- Тайлова система та переміщення гравця.
  
- Взаємодія з об'єктами, персонажами та тайлами.
  
- RPG-система боїв, характеристики та інвентар.
  
- Дослідження карти, збір грибів та інших ресурсів.
  
- Консольні анімації та візуальний декор.
  
- Сюжет, діалоги й ігрові завдання.
  

## 👥 Розподіл роботи

### 👤 Новицький Вячеслав (UAPvP) — Основа гри

**Відповідальний за базову архітектуру та ігрові механіки.**
